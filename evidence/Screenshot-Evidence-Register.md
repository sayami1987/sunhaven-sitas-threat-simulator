# Screenshot Evidence Register

Only actual captured application or browser views are screenshots. Diagram PNG
exports are engineering artefacts, not screenshots. Text logs preserve actual
command output where a native screen capture is unavailable. Missing captures
remain explicitly pending and must not be inferred from exported images.
